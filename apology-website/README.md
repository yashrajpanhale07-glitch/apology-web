# A little apology website

Open `index.html` in a browser. It has five pages: welcome, apology note, memories, pinky promise, and final question.

## Personalize it

Edit `assets/config.js` to change names, the apology note, memory cards, and promises. No HTML changes are needed for normal content edits.

## Add your own images or GIFs

The site works without external downloads. To use your own media, place an image or GIF in `assets/images/` and add a normal image tag to the page you want, such as `<img src="assets/images/cute-bear.gif" alt="Cute bear waving">`.
